# Titanic Survival Prediction 🚢

## Project Overview
A machine learning project developed to predict whether passengers aboard the Titanic survived or not, using Python and Scikit-learn.

## Project Objectives
- Explore and understand the Titanic dataset.
- Handle missing values.
- Perform exploratory data analysis.
- Engineer new features.
- Encode categorical variables.
- Train and evaluate machine learning models.
- Generate predictions for the Kaggle test dataset.

## Models Trained

| Model | Validation Accuracy |
|---|---:|
| Logistic Regression | 83.24% |
| Random Forest | 80.45% |
| Tuned Random Forest | 82.12% |

Logistic Regression was selected for the final Kaggle submission.
